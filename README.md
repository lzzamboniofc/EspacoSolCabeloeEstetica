# Espaço Sol — Site Institucional

Protótipo institucional em HTML, CSS e JavaScript puro, responsivo, mobile-first e sem build.

## Abrir
Abra `index.html` diretamente no navegador ou use um servidor local (ex.: Live Server do VS Code).

## Onde editar informações
Os dados principais ficam em:

`assets/js/config.js`

Ali você pode alterar:
- WhatsApp e mensagem inicial;
- Instagram;
- endereço;
- lista de serviços.

## Observação importante
Os serviços exibidos no protótipo são sugestões de conteúdo para apresentação comercial. Confirme com o estabelecimento quais procedimentos realmente oferece antes da publicação definitiva.

## Imagem
A logo enviada foi otimizada em WebP e está em `assets/img/logo.webp`.


## Responsividade
A folha de estilos parte do layout para celulares e evolui por breakpoints para tablet e desktop. A faixa animada (marquee) foi removida para manter a navegação mais limpa e leve no mobile.
